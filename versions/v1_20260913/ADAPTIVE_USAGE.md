# 曲面姿态跟随版

旧入口 `./run.sh execute` 保留原来的固定姿态版本。新入口为 `./run.sh adaptive_execute`。
本次只做软件改进和离线验证，未运行新的变姿态实机擦拭。

## 已改进

- 沿弧长平滑局部法向及切向，平滑偏差超过 10° 拒绝执行。
- 连续旋转插值生成工具姿态。工具 +Z 指向工件，外法向 n = -Z。
- 每周期命令：T_base_ee = T_base_tcp @ inverse(T_ee_tcp)，其中 TCP 位置 = nominal + offset * n。
- 正反向查询同一个姿态场，回程不翻转工具。
- 最高 5 mm/s，短时间平滑加减速、中段匀速。按姿态角速度/角加速度限制自动降低进给。
- 使用当前实测 EE 姿态进行六维重力、偏置补偿及 TCP 力矩换算；在 base frame 滤波后投影到局部法向。
- 保留未滤波补偿力的超力保护、关节2提前停止保护和50 ms硬超时。
- 新外环目标100 Hz。轻度迟到冻结路径和力积分，不追赶积压时间；连续迟到中止。
- 日志保存原始六维值、补偿/滤波力、法向、命令/实际姿态、轨迹进度与修正量。结束后生成力曲线、均值、标准差、RMSE等。

## 离线预检查

```bash
cd /home/pnp/curve_wipe_demo
./run.sh adaptive_execute --plan output/live_016/selected_plan.json --force 1 --speed-mm-s 5
```

这条命令不连接机器人。该历史轨迹仅用于离线比较，不能作为新运行的实时场景依据。
同一条约95.8mm路径，旧轨迹公式单程约59.9秒；新时间参数化预估约21秒。
这是规划时间比较，不是实机性能验收。

## 实机前仍需完成

1. 当前传感器到EE的实际安装变换 T_ee_sensor。
2. 当前工具的六维偏置、重力向量和传感器坐标系质心参数。
3. 悬空多姿态独立检查：补偿接触力接近零，确认传感器符号。
4. 工具在悬空状态对齐新轨迹首点姿态，再重新扫描。执行入口检查首点姿态差<=2°、离面>=40mm、接近距离默认<=500mm（可用 `--max-approach-mm` 配置）。

`config/gravity_calibration.example.json` 仅说明文件格式，含占位值，默认无法执行。
不要用旧白板标定或固定姿态 tare 替代当前变姿态标定，不要直接修改状态字段绕过检查。
`validated_current_mount` 表示操作者已完成上述当前安装的物理验证；程序仍会在运行前检查当前悬空残余力。

完成标定后，命令形式为：

```bash
./run.sh adaptive_execute --plan <本次新扫描的plan.json> --segment 0 \
  --calibration <当前已验证的重力标定.json> --force 1 --speed-mm-s 5 \
  --execute --log output/adaptive_run.json
```

新入口没有自动清除机器人故障。异常只停止，不盲目退回；50ms硬超时仍会停止。
法向跟随不能保证长方形刚性擦面在任意曲率上全幅贴合，仍受擦子尺寸和软垫形变限制。
